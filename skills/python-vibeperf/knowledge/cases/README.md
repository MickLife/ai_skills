# 真实案例证据索引

本目录只保存真实优化案例的证据摘要和必要上下文。案例用于追溯知识来源，不是主流程默认读取的知识正文。

## 读取规则

- 主流程默认只读取本索引，不读取所有案例正文。
- 只有当当前问题与某个案例的“问题类型、数据规模、风险标签”高度匹配，或需要核验证据来源时，才读取单个案例文件。
- 小上下文模型应优先使用 `principles/`、`libraries/` 和 `domains/` 中的通用条目，避免被项目案例污染判断。

## 写入规则

案例必须具备：

- profile、benchmark 或测试证据。
- 测试环境、数据规模和统计方法。
- 可迁移经验和不可迁移细节。
- 至少一个反链到 `principles/`、`libraries/` 或 `domains/` 的知识条目。

禁止写入：

- 没有环境和统计方法的性能数字。
- 完整业务代码、完整 trace 或长 benchmark 表。
- 项目私有字段、目录结构和函数名的无过滤复刻。
- 没有抽象价值的一次性实现记录。

## 案例摘要格式

```markdown
| 案例 | 问题类型 | 关联知识 | 数据规模 | 提升摘要 | 风险标签 |
| --- | --- | --- | --- | --- | --- |
| `YYYYMMDD-topic.md` | 重复计算 / I/O / 空间索引 | `libraries/numpy.md#...` | N=... | 仅描述本案例结果 | 版本 / 内存 / 语义 |
```
