# BEV 渲染方式说明

本文件描述点云 BEV 图像的生成方式。实际使用前，应补充项目内真实渲染参数。

## 必填信息

- 坐标系：例如 `map_enu`、`utm`、局部地图坐标系。
- BEV 分辨率：每个像素对应的实际距离，例如 `0.05 m/pixel`。
- 图像原点：左上角、左下角或其他定义。
- x/y 轴方向：图像横轴、纵轴分别对应地图坐标的哪个方向。
- 高度范围：参与渲染的 z 范围。
- 点云来源：单车、多车、多趟采集或融合结果。
- 语义来源：模型分割、规则标注、人工标注或融合语义。
- 轨迹 overlay 方式：轨迹颜色、线宽、采样频率、是否区分车辆或采集批次。

## 推荐渲染层

为了提高 zero-shot 检测稳定性，建议尽量提供以下图层：

- 语义 BEV 图：用于识别结构重复和语义错位。
- 高度 BEV 图：用于发现双高度、上下错层和局部高度断层。
- 强度或密度 BEV 图：用于发现重影、点云稀疏和多趟采集叠加异常。
- 轨迹 overlay 图：用于关联异常区域与采集轨迹、配准漂移或多车融合问题。

## 模型使用约束

- 多模态模型只能基于提供的渲染图和说明判断可见异常。
- 地图坐标必须由确定性脚本根据瓦片元数据计算，不能由模型自由生成。
- 如果瓦片没有完整的像素到地图坐标转换关系，应只输出像素区域并标记人工复核。
