# BEV 语义颜色表

本文件描述 BEV 语义渲染图中颜色与地图语义类别的对应关系。实际使用前，应替换为项目内真实颜色表。

## 填写格式

| 颜色 RGB/HEX | 语义类别 | 说明 | 叠层检查重点 |
| --- | --- | --- | --- |
| `#RRGGBB` | road_surface | 路面 | 平坦区域是否出现双高度、重影或异常带状结构 |
| `#RRGGBB` | lane_marking | 车道线 | 是否出现平行重复线、局部错位或模糊加宽 |
| `#RRGGBB` | curb | 路沿 | 是否出现双路沿、重复边界或上下错层 |
| `#RRGGBB` | barrier | 护栏/隔离带 | 是否出现平行重复护栏或局部断裂错位 |
| `#RRGGBB` | building | 建筑/墙面 | 立面边界是否出现重复轮廓 |
| `#RRGGBB` | pole | 杆状物 | 是否出现同一杆状物多个偏移实例 |
| `#RRGGBB` | vegetation | 植被 | 植被噪声高，避免仅凭边缘毛刺判断叠层 |
| `#RRGGBB` | unknown | 未知/其他 | 仅作为辅助证据，不应单独触发高置信异常 |

## 使用要求

- 调用多模态模型前，必须把当前渲染图实际使用的颜色含义提供给模型。
- 如果颜色表缺失或与图像不匹配，应停止自动判定并要求用户补充。
- 对容易误检的语义类别，例如植被、动态物体、未知区域，应降低置信度并标记人工复核。
