# 人工复核清单

当模型输出疑似叠层区域后，人工复核人员应按以下步骤确认。

## 数据完整性

- [ ] 区域 ID 和对象存储路径正确。
- [ ] BEV 语义图、高度图、轨迹 overlay 与同一区域对齐。
- [ ] 语义颜色表与当前图像一致。
- [ ] 瓦片元数据完整，像素坐标可以转换为地图坐标。

## 异常证据

- [ ] 是否存在重复边界、重复轮廓、双高度或局部重影。
- [ ] 是否至少有两个独立证据支持叠层判断。
- [ ] 异常是否与多车、多趟采集或轨迹交汇区域相关。
- [ ] 异常是否影响可定位、可导航或可发布地图元素。

## 误检排除

- [ ] 是否为真实桥梁、匝道、隧道、高架或多层道路。
- [ ] 是否为真实双路沿、护栏、隔离带或施工结构。
- [ ] 是否由植被、动态物体、遮挡或点云稀疏造成。
- [ ] 是否只是渲染压缩、颜色混叠或下采样伪影。

## 结论

- [ ] 确认为叠层错误。
- [ ] 确认为正常结构或渲染伪影。
- [ ] 无法判断，需要补充点云剖面、原始轨迹或人工标注。
